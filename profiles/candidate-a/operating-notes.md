# Operating notes (for future AI / human readers)

## How to use this pack

- In Cursor, **`@`-reference** the repo root [`README.md`](../../README.md), this profile’s [`README.md`](./README.md), or the whole [`medical-research`](../../) folder.
- Shared links book: [`references/official-sources.md`](../../references/official-sources.md).
- Treat files as **living documentation**: update when new **official** facts arrive (NEET scorecard, GUJCET, counselling registration numbers, etc.).

## Authority hierarchy

1. **Official** PDFs and portals (NTA NEET, MCC, ACPUGMEC / Gujarat medical admission committee, NMC, state counselling sites).
2. **This markdown pack** — facts as stated by the user / extracted from their documents.
3. Third-party predictors, coaching blogs, YouTube — **optional**; never override (1) or contradict (2) without flagging uncertainty.

## Privacy

- Public version is de-identified. Keep any source documents with PII outside this repository.

## Known limitations of current data

- NEET **420 ± 10** is **self-estimated** post-exam — **not** official.
- **No confirmed NEET AIR** yet.
- **GUJCET** outcome not in record.
- **Budget / bond / location constraints** not captured — decisions will be incomplete until added.

## Suggested update triggers
