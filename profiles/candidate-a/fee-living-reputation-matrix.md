# Fees, living costs, hospitals, reputation, and “placement” — college reference

**Profile:** Candidate A (**male**, **Indian citizen**, Gujarat domicile, **General**) · pathways in [`gujarat-colleges.md`](./gujarat-colleges.md), [`mbbs-mumbai-pune-bengaluru.md`](./mbbs-mumbai-pune-bengaluru.md), [`egypt-cairo-medical-colleges.md`](./egypt-cairo-medical-colleges.md).

**Budgeting:** Primary focus remains **GQ / government / municipal / MQ / institutional (rupee)**. **NRI / overseas-category** columns are **kept below** with **₹ equivalents** so you can compare if **your counselling year’s rules** make you eligible for that pool *(many states require **NRI/OCI/sponsor** documentation — **read the official brochure**, not this table).*

**FX reference (USD → ₹ for this document):** **1 USD = ₹95** — rounded from public **USD/INR** quotes around **₹94.89–₹95.17** (early **May 2026**). **Not** a bank/remittance rate; **recompute** when you pay. Formula: **₹/yr ≈ (USD tuition/yr) × 95**; shown as **₹ lakh/yr** where helpful **(÷ 10⁵)**.

## MBBS India: “Placements” (wording)

Medical councils register graduates; employers do **not** “campus-place” doctors like IT firms. Interpret:

| Meaning | Typical reality |
|---------|----------------|
| **Clinical training / internship** | Linked to **affiliated teaching hospital(s)** listed on NMC and state notices; interns rotate there by rule. |
| **After MBBS** | **NEET-PG**, state service cadres, private hospital jobs abroad, research — merit + exams + licensing (e.g. **NEXT**/legacy screening evolution per **NMC/NBEMS** notices), not placement cells. |

So the **“Hospital affiliation”** column below is usually the materially relevant analogue of “placement” for UG medicine.

**Abbreviations**

- **GQ** = **Government quota** tuition (regulated pool inside that institute’s seats).
- **MQ** = **Management quota** tuition.
- **NRI / overseas** = fee for **NRI or overseas-category** seats in the **ACPUGMEC** PDF (often **USD/yr** or **₹ lakh/yr**). **Eligibility** for that pool is **not** automatic for every Indian citizen — verify **medadmgujarat.org** booklet.
